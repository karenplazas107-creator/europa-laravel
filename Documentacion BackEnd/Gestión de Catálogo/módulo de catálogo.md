# Módulo de Catálogo y Categorías de Productos

Este módulo funciona como el catálogo general o vitrina de consulta de **Almacén Europa**. Fue diseñado para que los empleados del almacén puedan revisar de manera rápida, visual y organizada todos los productos que tenemos disponibles para la venta, agrupados por sus respectivas categorías.

---

## 1. ¿Para qué sirve este módulo?

Este módulo cumple varias funciones prácticas en el día a día del negocio:
- Permite consultar todo el inventario de productos de forma visual con sus fotografías y precios.
- Ayuda a ubicar productos rápidamente mediante un buscador en tiempo real.
- Permite filtrar por categorías específicas (por ejemplo: Perfumería, Cuidado Facial, Accesorios, etc.).
- Muestra tarjetas de alerta en la parte superior para saber de un vistazo cuántos productos se están agotando o cuáles ya están en cero unidades.
- Ofrece la posibilidad de cambiar el estilo de visualización entre tarjetas con fotos o una tabla tipo lista rápida.

---

## 2. ¿Quiénes utilizan este módulo?

Este módulo está disponible para el equipo operativo de la tienda:
- **Vendedores:** Para mostrarle opciones al cliente en el mostrador, consultar características de un producto o verificar el precio al instante.
- **Personal de Bodega:** Para ubicar referencias y saber qué familias de productos tienen pocas unidades.
- **Administrador:** Para supervisar la variedad del catálogo y verificar que los productos tengan su fotografía y datos completos.

---

## 3. Paso a paso: Cómo se utiliza el Catálogo

El manejo del catálogo es muy sencillo e intuitivo. Así es como se utiliza en la práctica:

### Paso 1: Ingreso al módulo
El empleado hace clic en la opción **"Catálogo"** en el menú de navegación principal. De inmediato se abre la pantalla principal con todos los productos registrados.

### Paso 2: Lectura de las tarjetas de resumen (arriba de la pantalla)
En la parte superior, el sistema muestra 4 tarjetas informativas con números clave actualizados al momento:
1. **Total de Productos:** Cuántas referencias distintas tiene la tienda en total.
2. **Total de Categorías:** Cuántas clasificaciones o familias comerciales tenemos activas.
3. **Stock Bajo:** Cantidad de productos a los que les quedan 10 unidades o menos. Esto sirve como una alerta amarilla preventiva para hacer pedidos a los proveedores a tiempo.
4. **Sin Stock:** Cuántos productos están completamente agotados (en 0 unidades). Aparece en color de alerta para avisar que no se pueden ofrecer hasta que llegue nuevo pedido.

### Paso 3: Búsqueda de un producto
Si se necesita localizar un artículo en específico, se utiliza la barra de búsqueda ubicada en la parte superior:
- Se puede escribir el nombre del producto (por ejemplo: "Perfume Carolina Herrera").
- Se puede escribir una palabra de la descripción (por ejemplo: "vainilla", "amaderado", "crema").
- También se puede pasar el lector de código de barras o escribir el código del producto.
Al escribir o presionar buscar, el catálogo filtra inmediatamente los artículos que coinciden con lo que se busca.

### Paso 4: Filtrado por categorías
Al lado del buscador hay un menú desplegable de categorías:
- Por defecto muestra "Todas las categorías".
- Si se selecciona una en particular (por ejemplo, "Fragancias Masculinas"), el catálogo oculta los demás productos y deja únicamente los que pertenecen a esa familia comercial.
- Esto permite atender con rapidez cuando un cliente llega preguntando por una categoría en especial.

### Paso 5: Cambio de vista (Cuadrícula o Lista)
El sistema le permite al usuario elegir cómo prefiere ver la información con dos botones ubicados arriba a la derecha:
- **Modo Cuadrícula (Fotos Grandes):** Muestra cada producto como una tarjeta moderna con su fotografía en alta resolución, nombre, categoría, precio de venta destacado y una etiqueta de color que indica si hay unidades disponibles o si está agotado. Este modo es ideal para exhibir y ver la presentación del producto.
- **Modo Lista (Tabla Resumida):** Muestra los productos en filas compactas con columnas de código, nombre, categoría, precio y stock. Este modo es perfecto para hacer revisiones rápidas o chequear existencias en pocos segundos.

### Paso 6: Ver el detalle completo de un producto
Al hacer clic sobre cualquier producto, se despliega una ventana emergente donde se puede leer la descripción detallada del artículo, su código de barras completo, su precio y la cantidad exacta que queda en la bodega.

---

## 4. Indicadores de disponibilidad visual

Para facilitar la lectura rápida sin tener que abrir cada producto, cada tarjeta cuenta con un distintivo de color:
- **Verde ("Disponible"):** Significa que hay suficiente mercancía en existencia para vender con tranquilidad.
- **Naranja ("Pocas Unidades"):** Indica que quedan 10 unidades o menos en bodega, recomendando reabastecer pronto.
- **Rojo ("Agotado"):** Indica que el producto tiene 0 unidades, avisando al vendedor que no debe prometerlo hasta que llegue mercancía.
